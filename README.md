# Roblox Avatar Changer

This project contains a script to change the avatar in Roblox. It allows you to modify the appearance of player characters by applying different avatar descriptions.

## Install

1. Open Roblox Studio.
2. Create a new script in the `ServerScriptService`.
3. Copy the contents of `scripts/avatar_changer.server.lua` into the new script.
4. Replace the placeholder avatar ID (123456789) with the actual ID of the avatar you want to use.

## Use

1. Place the script in the `ServerScriptService` in Roblox Studio.
2. Publish the game.
3. When players join the game, their avatars will be changed to the specified avatar.
